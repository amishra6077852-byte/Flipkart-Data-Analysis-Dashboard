# 📊 Flipkart Data Analysis Dashboard | Power BI

## 📌 Project Overview
This project presents an interactive **Flipkart Data Dashboard** built using Microsoft Power BI. It visualizes sales, quantity, profit, payment modes, and product categories to help understand business performance through data-driven insights.

## 🚀 Dashboard Features
- **Sales Analysis:** Overview of total amount and sales-related metrics.
- **Quantity Analysis:** Insights into product quantities across categories.
- **Payment Mode Analysis:** Breakdown of COD, UPI, credit card, debit card, and EMI payments.
- **Monthly Profit Analysis:** Visualization of profit trends across months.
- **Category Analysis:** Comparison of clothing, electronics, and furniture.
- **Sub-category Analysis:** Comparison of products such as printers, bookcases, sofas, accessories, and tables.
- **Interactive Filters:** Quarterly filters for exploring data.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Data Analysis

## 🎯 Project Objective
The objective of this project is to convert business data into meaningful visual insights, making it easier to understand sales performance, customer payment preferences, product categories, and monthly profit trends.
